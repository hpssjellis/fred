Motor Node WebBLE Hub - v011

Connects to MULTIPLE XIAO motor nodes at once over Bluetooth (v010 only supported one connection at a time). Works in Chrome or Edge on desktop or Android (not iOS Safari - no Web Bluetooth support there).

v011 changes: each node gets its own concurrent GATT connection instead of sharing one global connection slot, so the Dashboard below can show live readings from every node in range at the same time instead of round-robin polling. Each node also gets an editable text label (stored in this browser's localStorage, keyed by the node's Bluetooth device id) so you can rename "XIAO-Anomaly-02" to something like "Line 3 Conveyor Motor" - the rename persists across page reloads on this browser/computer. Train / Collect / Capture / Model-upload remain single "active device" actions, since those are physical stand-at-the-machine tasks anyway.

Model & Calibration File Transfer (active device)

Same file path on the node's SD card either way. Download reads it off SD and saves it to your computer/phone. Upload sends a file from your computer/phone to the node - the node auto-loads it as soon as the transfer completes (auto-load only applies to the model weights file below; other files are just read/written as-is).

The node keeps three separate binary files under /header/:

  • /header/myAnomalyMLWeights.bin - trained model weights (Upload auto-loads this one)
  • /header/myCalib.bin - IMU calibration (accel mean/std), saved once at first boot
  • /header/myFeatureBaseline.bin - secondary per-axis RMS/P2P/ZCR baseline, built during Train
