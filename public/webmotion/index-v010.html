Model & Calibration File Transfer (Download / Upload)

Same file path on the node's SD card either way. Download reads it off SD and saves it to your computer/phone. Upload sends a file from your computer/phone to the node - the node auto-loads it as soon as the transfer completes (auto-load only applies to the model weights file below; other files are just read/written as-is).

The node keeps three separate binary files under /header/:

  • /header/myAnomalyMLWeights.bin - trained model weights (Upload auto-loads this one)
  • /header/myCalib.bin - IMU calibration (accel mean/std), saved once at first boot
  • /header/myFeatureBaseline.bin - secondary per-axis RMS/P2P/ZCR baseline, built during Train
